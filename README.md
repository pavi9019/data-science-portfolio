Data Science Portfolio
This repository is a central index of my data science projects, focused on applied machine learning, time series forecasting, and financial/risk analytics.

Project themes
The main projects showcased in this portfolio include:

House price prediction (regression) – Exploratory data analysis, feature engineering, and model comparison (linear regression, KNN, random forest, gradient boosting) on Washington State housing data.
Wine sales forecasting (time series) – Decomposition and forecasting of monthly wine sales using exponential smoothing, ARIMA/SARIMA, and baseline models.
Firm sales and crash survival (regression & classification) – Linear regression for firm sales alongside logistic regression and LDA models to predict survival in car crashes.
Financial risk analysis – Quantitative analysis and modelling of financial risk, including scenario-based insights for decision-making.
These projects originate from completed postgraduate coursework and capstone work and are being curated here as clean, reproducible code and notebook implementations.
